# Object Detection with a Lightweight Neural Network

This exercise builds on image *classification* Convolutional Neural Networks (CNNs), 
where a whole image gets one label. Object *detection* goes a step further: it 
locates *and* labels multiple objects within a single image using bounding boxes. 
You'll use MobileNet-SSD, a small ("mobile-friendly") pretrained neural network that
is light enough to run inference on CPU in well under a second, no GPU or training
required.

> [!IMPORTANT]
> Your results depend entirely on the specific image you choose — report which image
> you used, which objects were actually detected, and their confidence scores. These
> can't be pre-generated by an AI without seeing your actual image and its detections.

---

## Tasks

### Task 1 — Load the pretrained model
Download the two pretrained MobileNet-SSD model files (`deploy.prototxt` and
`mobilenet_iter_73000.caffemodel`, ~23 MB, one-time download) and load them with
`cv2.dnn.readNetFromCaffe`.

### Task 2 — Find your own image
Use Google image search to find a `.jpg` photo (size < 2 MB) containing at least 2-3
recognizable everyday objects, e.g. `person`, `car`, `dog`, `cat`, `bicycle`, `bus`,
`chair`, `bottle` (any of the 20 PASCAL VOC classes).

### Task 3 — Run object detection
- Preprocess the image into a blob (resize to 300x300, scale factor `0.007843`,
  mean subtraction `127.5`)
- Run a forward pass through the network
- Loop over the raw detections and filter out those below a confidence threshold
  (e.g. 0.4)

### Task 4 — Visualize and report
- Draw the remaining bounding boxes with their class label and confidence on the image,
  and display the result
- Report which image you used and the actual objects and confidence scores you detected

### Task 5 — Experiment with the confidence threshold
Re-run detection with a few different confidence thresholds of your choice (e.g. one low,
one around the 0.4 default, one quite high). Describe, based on your own re-runs, how the
number of detected (and false-positive) boxes changes as you vary the threshold.
